# Value scorecard

Use only metrics present in the supplied context or label the metric as proposed.

| Layer | Example evidence | Interpretation boundary |
|---|---|---|
| Adoption | Active-seat ratio, repeat workflow use | Indicates use, not business impact by itself |
| Operations | Completion time, backlog, incident volume | Compare like-for-like periods and cohorts |
| Business | Cost avoided, cycle time, protected revenue | State assumptions, source, unit, and attribution limit |
| Relationship | Champion coverage, executive alignment | Qualitative unless a defined scale exists |

## Measurement contract

For each value claim record:

1. metric name and source;
2. baseline and comparison period;
3. cohort and unit;
4. calculation and assumptions;
5. whether the result is observed, realized, expected, or a scenario;
6. validation owner and next measurement date.

For a scenario, show:

`scenario value = eligible volume × assumed improvement × verified unit value`

Show a low/base/high sensitivity when the assumed improvement or unit value is uncertain. Never use monthly revenue or revenue at risk as realized ROI.

## Example

Unsupported: “The platform saved $500,000 because churn probability fell.”

Supported: “If 8,000 eligible cases save 4–8 minutes each and the customer validates a $0.90 per-minute loaded cost, the annualized result is a scenario estimate of $28,800–$57,600. Validate eligible volume, sustained time savings, and unit cost before customer-facing use.”
