# Intervention outcome rules

## Classify each memory

| Memory evidence | Classification | Planning rule |
|---|---|---|
| Action recorded, no outcome | Insufficient evidence | Verify status before repeating or replacing |
| Explicit rejection or negative outcome | Stop | Do not repeat the same lever without materially changed conditions |
| Partial outcome with open blocker | Change | Preserve the useful component and address the blocker |
| Verified positive outcome | Continue candidate | Reuse only under comparable workflow, cohort, and timing |
| Contradictory records | Uncertain | Preserve both, lower confidence, and request validation |
| Generated summary without underlying event | Context only | Do not treat as authoritative outcome |

## Comparison test

Before reusing a tactic, compare:

- target workflow;
- user cohort;
- underlying blocker;
- delivery channel;
- accountable owner;
- measurement and time window;
- renewal and commercial context.

If a material condition differs, describe reuse as a new experiment rather than evidence that the tactic will succeed.

## Examples

Wrong: “A discount was previously mentioned, so it worked.”

Right: “Memory records a prior discount but no outcome; verify the result before treating it as effective.”

Wrong: “Repeat the same generic discount that was recorded as ineffective.”

Right: “Stop discount-led retention and test a workflow adoption recovery plan tied to a measurable outcome. Any commercial offer remains approval-gated.”
